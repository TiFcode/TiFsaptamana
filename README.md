# TiFsaptamana — Săptămâna mea

Joc educativ touch-friendly, în limba română, pentru formarea noțiunii de zile ale săptămânii prin rutine familiare.

## Activități

- **Descoperă**: parcurge zilele în succesiune și ascultă numele fiecăreia.
- **Unde merg?**: alege între grădiniță și acasă pentru ziua afișată.
- **Pune în ordine**: construiește săptămâna de la Luni la Duminică.

Programul este fix: grădiniță de luni până vineri, iar sâmbătă și duminică sunt zile acasă / weekend. Butonul de pronunție folosește explicit vocea română (`ro-RO`) atunci când browserul o are disponibilă.
